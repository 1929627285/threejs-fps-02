BREAKWATER: a round-based tactical FPS in a harbor freight terminal at dusk. Two teams of five, short rounds won by elimination or by planting and defending the charge, money and a buy menu between rounds, and gunfire where stopping to aim pays. Single-player against nine bots with routes, hold positions, vision and hearing. Runs offline from static files — no build step, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
